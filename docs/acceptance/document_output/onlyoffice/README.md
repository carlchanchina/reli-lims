# ONLYOFFICE 原生引擎兼容验收

2026-10-29 使用用户提供环境中现有的 ONLYOFFICE Document Server `x2t 10.0.0.169` 验收。仅把虚构示例放入专用临时目录，直接调用已有原生导入／排版引擎，不修改容器服务配置，不部署代码，不为 Reli LIMS 新增 ONLYOFFICE／Drive 接入。

三份 XLSX、三份 DOCX 均成功原生加载并打印 PDF，退出码全部为 0。输入 SHA-256 与仓库六份示例一致；输出 PDF、页数与哈希见 `manifest.json`。报价单中文、三行明细、4800 总计、条款和签字区完整。报价 XLSX 在此引擎打印两页，签字区位于第二页；两张 PNG 记录实际版式。

额外验证两个 5600 多字的条款／结论工作簿。直接转换默认只打印活动表，因此在临时副本中选择既有“续页”再打印；两份续页各三页，末尾标记及完整文本字符计数核对通过。交付示例和模板未因验收改变。打印长文本应选择续页或打印整本工作簿。

本项证明既有 ONLYOFFICE 原生引擎能够读取和渲染交付文件；没有宣称手工操作过浏览器编辑器，也不代表 Microsoft Excel 专项验收。此处 PDF 为兼容验收证据，正式九份业务示例仍在 `docs/examples/document_output/`。
