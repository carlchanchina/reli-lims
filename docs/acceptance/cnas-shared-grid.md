# CNAS 明细表验收

环境为 192.168.10.204 的 Carl 开发站，site `carl`。验收使用现有 CNAS 批次和明确命名的开发草稿。

| 页面 | 验收结果 |
| --- | --- |
| `/desk/reli-lims/capability-source/CAPSRC-00499` → CNAS 能力明细表 | Desk 可翻到第二页并展开行，从电阻器／冲击试验行跳到原始能力。服务端遍历 22 页，取得 650 个唯一记录。 |
| `/desk/selling/quotation/SAL-QTN-2026-00005` | 浏览器保存了疲劳载荷试验和玻璃粘接强度试验两行。编辑了疲劳行的检测条件原文，保存后仍可见。 |
| `/desk/reli-lims/test-request/REQ-01150` → 检测项目与条件 | 浏览器通过报价入口打开委托并核对了两行快照。保存的开发验收样本由后端用同一映射创建，Desk 重新打开后确认两个项目都显示同一个样品。 |

数据库样例：`REQ-01150` 的 `CAP-1` 指向 `CAP-00501`，中文名为疲劳载荷试验，来源报价为 `SAL-QTN-2026-00005`，条件原文为「DEV 验收：循环载荷与保持时间按客户样件约定」。`CAP-2` 指向 `CAP-00500`，中文名为玻璃粘接强度试验。两个项目通过独立关联行连接样品 `S1`。报价和委托均为草稿。

当前批次的验收使用条件原文，没有把试验限制推断成温度、时长等输入。结构化条件由具体能力的模板配置。全系统显示及打印输出尚未完成逐项验收。

11 月 5 日补验：在 Carl 开发站的待确认能力 CAP-00501 添加可选测试模板「保持时间（分钟）」，保留条件原文。在 Desk 将验收报价 SAL-QTN-2026-00005 的保持时间设为 15，保存后从数据库读取并验证转委托映射中的值为数值 15。使用应用的「生成文档」渲染器生成有效报价 PDF，打印数据包含中文服务名和条件，不含 Item 编码。ERPNext 原生打印另有自己的版式。本次运行 54 项 Python 回归。

11 月 5 日 Desk 补验：打开 CAPSRC-00499 多行能力表、已保存的两行报价 SAL-QTN-2026-00005，再点击「发起检测委托」查看新委托草稿。截图覆盖这三个页面。新草稿中的疲劳载荷试验保有中文方法、UIC 566:1990 中文标准标题和 15 分钟条件。通过报价页面「生成文档」取得私有 PDF 附件。独立原生打印版式 Reli CNAS Quotation 在 Carl 对同一份报价渲染成功，两行均显示中文服务名称，均无内部 Item 编码。该版式由用户选择，ERPNext 默认 Standard 版式沿用原有设置。
