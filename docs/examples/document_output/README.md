# 文档输出示例

这些文件由隔离站点的原生 Quotation、Test Request、Test Report 经正式输出服务生成，再从私有附件取回。全部为明确标记的虚构示例，不能用于真实报价、委托或证明检测合格。

| 源单据 | PDF | Word | Excel |
|---|---|---|---|
| Quotation | [报价 PDF](检测报价单-示例.pdf) | [报价 Word](检测报价单-示例.docx) | [报价 Excel](检测报价单-示例.xlsx) |
| Test Request | [委托 PDF](检测委托单-示例.pdf) | [委托 Word](检测委托单-示例.docx) | [委托 Excel](检测委托单-示例.xlsx) |
| Test Report | [报告 PDF](检测报告-示例.pdf) | [报告 Word](检测报告-示例.docx) | [报告 Excel](检测报告-示例.xlsx) |

`manifest.json` 记录源单据编号、格式、MIME、大小、SHA-256 及源附件私有属性；下载文件统一改为便于识别的示例名称。源单据和附件属于隔离测试环境，不作为生产交付数据。报告示例保留未签发标记。
