# 委托商业来源关联

Test Request 可独立手工创建，无报价／订单也可提交。可选关联 ERPNext Quotation 和 Sales Order；仅接受已提交商业单据，客户和公司必须与委托一致，并要求操作者有来源读取权限。若同时选择报价和订单，该订单至少一条明细必须引用选定报价。不复制报价／订单商品为实际 Sample 或检测项目，不据此自动收样或提交。复制委托时不复制商业来源。

商业单据不代表客户已确认检测要求；实验室确认仍由 Lab Manager 提交委托后创建 Project。一个报价／订单可能分批委托，因此手工关联不设全局唯一约束。

本轮仅复用上述已完成的可选来源关联；不接门户、第三方协作或 Bridge，不开放外部用户的写入／客户确认能力。
